# Prova Paulista — Correção | Gestão de Operações 51067

Jogo educativo estático pronto para publicação na Vercel.

## Conteúdo
- Capa com a imagem fornecida e botão **INICIAR JOGO**.
- Questões **11 a 16**, exclusivamente da seção **Gestão de Operações - 51067**.
- Questões de resposta única e múltipla.
- Gráfico de Gantt da questão 16 incluído.
- Feedback imediato: **PARABÉNS! VOCÊ ACERTOU!** ou **QUE PENA, VOCÊ ERROU!**
- Gabarito explicativo após cada resposta.
- Cronômetro e pontuação.
- Animação de moedas.
- Áudio fornecido para acerto e erro.
- Layout responsivo para computador, tablet e celular.

## Publicar na Vercel
1. Descompacte o ZIP.
2. Entre na Vercel e escolha **Add New → Project**.
3. Faça upload/importação da pasta do projeto.
4. Framework: **Other** (site estático).
5. Build Command: deixe vazio.
6. Output Directory: `.`.
7. Deploy.

Não há dependências de Node ou backend.

## Observação
O conteúdo das questões e dos gabaritos foi transcrito da seção **Gestão de Operações - 51067** do PDF fornecido.
